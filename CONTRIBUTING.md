# Contributing to GameCrew AI

Thank you for improving the project.

1. Open an issue describing the problem or proposal.
2. Keep changes focused and add a reproducible test where behavior changes.
3. Run `node --test tests/gamecrew-ai.test.mjs` before opening a pull request.
4. Do not include credentials, confidential data, copyrighted game assets, or unsupported performance claims.
5. Explain how your change preserves the distinction between facts, assumptions and recommendations.
